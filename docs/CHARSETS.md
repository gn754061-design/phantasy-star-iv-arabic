# جداول المحارف — Phantasy Star IV (USA)

## 1) جدول حوار اللغة الإنجليزية (`script/charset.asm`)
مصدره التفكيك `squidfeatures/ps4disasm`، وهو الجدول الذي تُترجم به الـ43 كتلة حوار.

| النطاق | المعنى |
|---|---|
| `0x00` | مسافة (space) |
| `0x01–0x1A` | `A–Z` |
| `0x1B–0x34` | `a–z` |
| `0x35–0x3F` | ترقим (`.` `'` `,` `·` `:` `!` `?` `-` …) |
| `0x40–0x49` | `0–9` |
| `0xFC` | سطر جديد (newline) |
| `0xFD` | مؤشر السهم (arrow cursor / wait) |
| `0xFE` | إغلاق النافذة ومتابعة الحوار |
| `0xFF` | نهاية الحوار (terminator) |
| `0xF2–0xFA` | أكواد أحداث/صور/صوت/خيارات (انظر `script/documentation.txt`) |

## 2) جدول نوافذ القوائم (`general/tables/wincharset.asm`)
| النطاق | المعنى |
|---|---|
| `0x01–0x1A` | `A–Z` |
| `0x39–0x52` | `a–z` |
| `0x1B–0x24` | `0–9` |
| `0x00` | مسافة |

## 3) جدول التعريب العربي (`extract/font/arabic_map.tbl`)
- 175 محرفاً عربياً (أشكال Presentation Forms-A/B، الأرقام الهندية، علامات الترقيم، وحروف لاتينية كبيرة للمصطلحات).
- القيم من `0x01` إلى `0xAF` تقريباً؛ كل قيمة هي **رقم الجليف** في `extract/font/arabic_font.bin`.
- الجليف `0x00` = مسافة.
- أكواد التحكم `0xFC/0xFD/0xFE/0xFF` **لا تُلمس** أبداً.
- رقّعنا `GetFontGraphics` لتغيير القناع من `andi.w #$7F,d1` إلى `andi.w #$FF,d1`، مما يرفع سعة الخط إلى 256 جليفاً.
- بايتات `>= 0xE0` في المحرك تعني "خُذ البايت التالي كرقم جليف"، لذلك توقفت الخريطة عند `0xDF`.

## 4) تحويل النص العربي
```
نص UTF-8 → arabic_reshaper.reshape() → bidi.get_display() → جدول arabic_map.tbl → بايتات اللعبة
```
لا يُمرَّر أي كود تحكم عبر إعادة التشكيل؛ السكربتات تعمل على أسطر `dc.b "..."` مستقلة.
